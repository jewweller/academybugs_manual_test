# Тестирование интернет-магазина AcademyBugs

Ручное тестирование учебного интернет-магазина [AcademyBugs](https://academybugs.com/find-bugs/). Это стенд с заранее заложенными дефектами. Я составил тест-кейсы, прошёл их и оформил баг-репорты и итоговый отчёт.

Вся документация в файле [AcademyBugs_test_documentation.xlsx](AcademyBugs_test_documentation.xlsx):

| Лист | Что внутри |
|---|---|
| Тест-кейсы | 23 тест-кейса с предусловиями, шагами, ожидаемым и фактическим результатом |
| Баг-репорты | 13 записей: 12 дефектов и 1 предложение по улучшению |
| Отчёт | Сводка по статусам кейсов и серьёзности дефектов, вывод о готовности к релизу |

## Что проверял

- Каталог: отображение карточек, переход в карточку товара, сортировка, количество товаров на странице
- Карточка товара: смена валюты, фото, ссылка на производителя, отзывы
- Корзина: добавление, изменение количества, удаление, граничные значения количества (0, -1, очень большое число)
- Аккаунт и регистрация: форма входа, страница аккаунта, регистрация с пустыми полями
- Оформление заказа: заказ с валидными данными, проверка полей телефона и города

Не проверял: реальную оплату (на стенде заказ не создаётся), нагрузку и безопасность.

## Подход

- Тест-дизайн: классы эквивалентности и граничные значения для поля количества, позитивные и негативные проверки форм
- Один тест-кейс проверяет одну вещь, у каждого кейса конкретные тестовые данные
- Баг-репорт заводится на каждое расхождение с ожидаемым результатом. Если кейс нельзя пройти из-за другого дефекта, кейс получает статус Blocked и ссылку на этот дефект
- Окружение: macOS, Chrome 155

## Основные дефекты

**BUG-004, Critical.** В корзине количество товара сбрасывается до 2 после нажатия «Update», если ввести больше 2. Купить нужное количество товара нельзя.

**BUG-002, BUG-012, BUG-013, Major.** Страница зависает примерно на 5 секунд в трёх местах: при смене валюты, при выборе 50 товаров на странице и при публикации отзыва. Возможно, у дефектов одна причина. Из-за зависания при публикации отзыва не удалось проверить валидацию email (TC-023, Blocked).

**BUG-010, Minor.** В форме оформления заказа поле телефона принимает значение «1», ошибки нет, заказ можно оформить дальше.

**BUG-011, Improvement.** Поле города принимает любое значение. Требований к полю нет, поэтому это оформлено как предложение по улучшению, а не как дефект.
